# Photo Browser 界面约定

应用沿用现有经典浅色、奶油贴纸、石墨深色主题；官网沿用深色、靛蓝和青色的品牌表达。优化以真实照片、明确任务、准确支持范围和可完成的操作为依据。

- 默认不在按钮、链接、导航和入口上附加装饰性箭头、chevron 或悬停箭头。排序与必要的图像切换保留最小方向表达。FAQ 展开使用文字状态。
- 官网展示真实应用截图；样片来源留在 site/assets/SOURCES.md，不使用私人照片或伪造拍摄参数。
- 下载前明确支持的平台、未公证状态与首次安装步骤。版本号和下载地址由已发布 Release 注入，不能提前展示尚不可下载的版本。
- 未实现的格式不列为支持；RAW 当前不支持。空文件夹、筛选无结果和扫描中分别提供准确提示与恢复操作。
- 桌面与手机均能找到下载、安装和反馈入口。保留键盘焦点、降低动态效果偏好、脚本不可用时的基础内容。
